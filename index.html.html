ℹ️ About ResumeIQ
🧠
AI-Powered — Uses your own free Google Gemini API key to genuinely read and reason about your resume for any target role, with an automatic offline keyword-scan fallback if AI is unavailable.
🎓
Smart Education Detection — Detects B.Tech, MBA, MCA, B.Sc, PhD and more from your resume text.
📊
Accurate Skill % — Separate required & preferred skill match percentages with correct counts.
🏢
Company Hiring Chances — See which companies you can realistically apply to with hiring probability.
💾
Saved Locally — Your profile and resume text stay only in this browser's storage.
📄
PDF Export — Download any report as a clean, shareable PDF straight from your browser — no upload or third-party service involved.
🧠 Analysis Mode

Default to AI-Powered Analysis

When on, new analyses use Gemini by default. Turn off to always use the fast offline scan. The Gemini API key is set directly in the code (search for GEMINI_API_KEY near the top of the script) rather than typed in here.
